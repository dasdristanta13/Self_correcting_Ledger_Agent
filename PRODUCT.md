# Product

register: product

## Purpose
Ledger Agent reads supplier invoice PDFs, checks the arithmetic, and corrects extraction errors only when the invoice's own text proves the correct value. The UI makes every correction inspectable: what changed, why, from which page/table/row, with what confidence.

## Users
Accounts-payable clerks and finance reviewers working through a queue of invoices at a desk. They need to triage fast (what needs me?) and verify precisely (why did the agent change this?).

## Brand personality
Calm, precise, auditable. A careful colleague with a red pen, not a dashboard trying to impress.

## Anti-references
Glassmorphism dashboards, purple-to-blue gradient SaaS, hero-metric stat cards, emoji icons, fake window chrome, cream/sand "editorial" palettes.

## Principles
1. Evidence before assertion: every number the UI states comes from data or is labeled as derived or preview.
2. Triage first: the first screen answers "what needs my attention?".
3. Status is never colour alone: text plus a shape.
4. Quiet by default, loud only for exceptions.
5. Keyboard and screen-reader complete; light and dark equal citizens.
